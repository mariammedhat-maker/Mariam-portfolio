# Mariam Medhat Ali — Portfolio

A modern, responsive one-page AI/ML portfolio built with pure HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio structure/content
- `style.css` — design, responsive layout, animations
- `script.js` — interactions, mobile menu, reveal animations

## Run locally

Open `index.html` directly in your browser, or use VS Code + Live Server.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub to publish the site.
